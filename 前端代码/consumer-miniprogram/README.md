# consumer-miniprogram — 消费者端小程序

"药途寻迹"中药材溯源系统**消费者端微信小程序**，面向终端消费者，提供产品溯源查询、AI 中医专家咨询、市场行情浏览等功能。

## 项目信息

- **源码目录**：`src/`
- **编译输出**：`dist/`（由 Gulp 构建生成，不提交到 Git）

## 页面功能

```
src/pages/
├── index/          # 首页（溯源码输入入口、功能导航）
├── trace/          # 溯源查询结果（展示全链路种植→加工→检验→物流信息）
├── ai-consult/     # AI 中医专家咨询（基于腾讯混元 Lite）
├── market/         # 中药材市场行情浏览
└── user/           # 个人中心（查询历史、设置）
```

## 核心功能

- **溯源查询**：扫描商品二维码或手动输入溯源码，即可查看该批次从产地到售出的完整信息，包括种植地块、加工工厂、检验报告、物流轨迹，以及可选的区块链存证哈希。
- **AI 中医咨询**：内置 AI 中医专家对话，帮助消费者了解中药材功效、用法与注意事项。
- **市场行情**：提供常见中药材市场价格参考信息。

## 本地开发

```bash
# 安装依赖
npm install

# 开发构建（监听模式）
npx gulp watch

# 生产构建
npx gulp build
```

构建完成后，使用微信开发者工具打开 `dist/` 目录预览调试。

## 配置说明

后端 API 地址配置在 `src/utils/config.js`，需与部署的后端服务地址保持一致。
