# 前端代码

本目录包含"药途寻迹"中药材溯源系统的所有前端微信小程序代码。

## 目录结构

```
前端代码/
├── miniprogram-5/          # 管理端小程序（多角色管理后台）
└── consumer-miniprogram/   # 消费者端小程序（用户溯源查询）
```

## 子项目简介

### miniprogram-5 — 管理端小程序

面向企业内部多角色用户（管理员、种植户、工厂、物流、监管人员），提供全链路数据录入与管理功能：

- 批次管理（创建、查看、GS1-128 条码生成）
- 种植环节记录（地块信息、生长周期、凭证图片）
- 加工环节记录（产线管理、加工记录）
- 质量检验管理（检验单录入、结果追踪）
- 物流环节管理（发货单、实时事件坐标上报）
- 区块链存证（可选 EVM 链上锚定）
- RBAC 权限控制（基于角色的访问控制）
- 用户管理后台

**微信 AppID**：`wxb6004f50990df687`

### consumer-miniprogram — 消费者端小程序

面向终端消费者，提供产品溯源查询与 AI 中医咨询功能：

- 扫码/手动输入溯源码查询全链路信息
- AI 中医专家在线咨询（基于腾讯混元 Lite）
- 中药材市场行情浏览
- 个人中心与历史记录

## 快速开始

1. 进入对应子项目目录
2. 安装依赖：`npm install`
3. 执行构建（将 Tailwind 编译为小程序可用样式）：`npm run build` 或 `gulp`
4. 使用微信开发者工具打开项目，选择对应 `dist/` 目录作为项目根目录
5. 在微信开发者工具中点击"预览"或"上传"

> **注意**：前端请求的后端 API 地址配置在各小程序的 `src/utils/config.js` 中，需根据实际部署环境修改。
