# Yaotu Trace Flat Mark

This icon is a square, flat, abstract mark for the Yaotu Trace project.

Design intent:
- 1:1 app-icon friendly proportion.
- Low-curve geometry: rectangular base, angled trace path, block nodes.
- Project semantics: herb origin, trace route, verification nodes, trusted record.
- Palette: medicinal green, light botanical background, restrained amber route.

Files:
- `yaotu-trace-flat-mark.svg`: editable vector source suitable for Figma import.
