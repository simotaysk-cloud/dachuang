# 测试数据

本目录包含系统开发与演示过程中使用的测试数据文件。

## 用途

- 为开发环境提供可复现的测试场景数据
- 用于功能演示与比赛展示时的数据准备
- 辅助接口调试，避免每次手动录入测试数据

## 说明

测试数据中的批次示例以"长白山人参"为基础样本，覆盖完整的溯源链路：

```
种植（产地信息）→ 加工（工厂处理）→ 质量检验（合格证明）→ 物流（运输记录）
```

演示批次 ID：`MOCK-2024001`

## 使用方式

如需通过代码自动注入演示数据，请使用后端提供的种子接口：

```
POST http://localhost:8091/dev/seed
```

或使用后端 `scripts/reset_demo_db.sh` 脚本直接重置数据库并写入测试数据。

> **注意**：测试数据仅供开发与演示环境使用，请勿导入生产数据库。
