# 小程序上架指南

本文档分两部分：
- 已在代码中完成（自动）
- 需要你在平台上完成（手动）

## 一、已在代码中完成（自动）

1. 移除前端默认本地 IP 依赖：
- `前端代码/miniprogram-5/utils/config.js` 默认改为 `https://api.example.com`
- `前端代码/miniprogram-5/utils/api.js` 默认改为 `https://api.example.com`

2. 移除登录页开发工具强制覆盖 URL：
- 删除 `pages/login/index.js` 中将 `baseUrl` 强制设为 `http://192.168...` 的逻辑。

3. 提供可视化后端地址配置入口：
- 首页增加“后端URL配置 + 保存并测试”。
- 登录页增加“后端URL配置 + 保存并测试”。

4. 文案统一为上架可用示例：
- 首页、登录页 URL 占位示例改为 `https://api.example.com`。

## 二、你需要手动完成（必须）

### 1) 准备生产后端

1. 准备公网域名（例如 `api.yourdomain.com`）。
2. 配置 HTTPS 证书（有效证书，链完整）。
3. 将后端部署到公网，确保接口可访问。
4. 用外网测试：
- `https://api.yourdomain.com/api/v1/health`

### 2) 微信公众平台配置合法域名

路径：小程序后台 -> 开发 -> 开发管理 -> 开发设置 -> 服务器域名

至少配置：
- request 合法域名：`https://api.yourdomain.com`

如果你使用了上传/下载/websocket，还要分别配置：
- uploadFile 合法域名
- downloadFile 合法域名
- socket 合法域名

注意：
- 必须是 HTTPS
- 不能带路径
- 域名需和小程序主体要求一致

### 3) 小程序合规项

1. 完成类目和服务内容描述。
2. 完成隐私政策并在小程序内可访问。
3. 完成备案（如平台要求）。
4. 准备测试账号（如审核要求提供）。

### 4) 上传与提审

1. 微信开发者工具 -> 上传，填写版本号和更新说明。
2. 平台“版本管理”中设置体验版，先内部验收。
3. 提交审核，填写审核说明（关键页面路径、测试步骤）。
4. 审核通过后发布（可灰度）。

### 5) 发布后检查

1. 真机验证登录、核心录入流程、扫码流程。
2. 验证防伪/上链查询结果是否正常。
3. 观察后端日志与异常告警。

## 三、推荐上线前最小验收清单

- [ ] 首页“后端URL配置”可修改并连通
- [ ] 登录成功并按角色跳转
- [ ] 批次创建/查询正常
- [ ] 加工、物流、质检主流程可走通
- [ ] 数据看板可读
- [ ] 安全防伪查询正常
- [ ] 无本地 IP / localhost 残留配置
