# 文档

本目录包含"药途寻迹"项目相关的业务分析、行业标准、政策法规与项目管理文档。

## 文档清单

| 文件 | 说明 |
|------|------|
| `GS1编码标准说明.docx` | GS1-128 国际条码标准在中药材溯源中的应用说明，包含编码规则、格式要求及集成方案 |
| `《中药材生产质量管理规范》.docx` | 国家中药材 GAP（Good Agricultural Practice）生产质量管理规范全文，是系统种植环节数据字段设计的依据 |
| `药品经营质量管理规范.doc` | 国家 GSP（Good Supply Practice）药品经营质量管理规范，是物流与流通环节合规要求的依据 |
| `区块链功能价值分析.docx` | 区块链存证功能的业务价值分析，包含防伪溯源场景、技术选型（EVM 兼容链）与成本收益评估 |
| `痛点-功能对应表.docx` | 行业痛点与系统功能模块的对应关系梳理，用于展示系统解决真实业务问题的逻辑 |
| `行业规则清单.docx` | 中药材行业相关法规、标准及合规要求清单 |
| `计划书-项目推进计划.docx` | 项目开发里程碑与时间安排 |
| `计划书-资料归档规范.docx` | 项目文档归档的命名规范与分类标准 |
| `小程序上架指南.md` | 微信小程序提交审核与上架流程说明，包含资质材料、类目选择与常见审核注意事项 |

## 文档用途说明

- **行业标准文档**（GAP、GSP、GS1）是系统数据模型与字段设计的规范依据，开发新功能时应参考。
- **痛点-功能对应表** 与 **区块链功能价值分析** 适合用于项目路演与答辩展示。
- **计划书** 系列文档用于比赛材料归档与进度汇报。
- **小程序上架指南** 供正式发布时参考，包含申请相关资质的步骤。
