# dev — 开发与演示工具模块

本模块提供开发环境下的辅助功能，包括演示数据生成、数据库重置与运维调试接口。**该模块的接口仅供开发/演示环境使用，生产环境部署时应禁用或限制访问。**

## 包结构

```
dev/
├── DevController.java          # 开发工具接口（/dev/* 路由）
├── DevMockDataSeeder.java      # 演示数据生成逻辑（完整溯源链路）
├── BulkSeederService.java      # 批量数据写入服务
└── DevOpsController.java       # 运维辅助接口（健康检查、环境信息）
```

## 主要接口

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/dev/seed` | 生成完整演示数据（批次 + 种植 + 加工 + 检验 + 物流） |
| POST | `/dev/seed/bulk` | 批量生成多条演示数据 |
| DELETE | `/dev/clean` | 清空所有业务数据（保留用户） |
| GET  | `/dev/status` | 查看当前数据库数据统计 |

## 演示数据说明

执行 `/dev/seed` 后会生成以"**长白山人参**"为样本的完整溯源链路：

```
批次 MOCK-2024001
├── 种植记录：吉林省长白山种植基地，2024-03-01 播种
├── 加工记录：某加工厂，2024-09-15 入库加工
├── 质量检验：检验合格，农残/重金属指标均达标
└── 物流记录：2024-10-01 发货，全程温度监控
```

## 生产环境安全提示

在 `application-prod.yml` 中禁用本模块：

```yaml
spring:
  profiles:
    exclude: dev
```

或在 Nginx / 安全组层面屏蔽 `/dev/*` 路径的外网访问。
