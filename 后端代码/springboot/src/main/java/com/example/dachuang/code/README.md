# code — GS1-128 条码生成模块

本模块负责按照 GS1-128 国际标准为每个中药材批次生成唯一溯源条码，确保编码格式符合行业规范，可与市场流通体系对接。

## 功能说明

- 根据批次信息生成符合 GS1-128 标准的条码字符串
- 支持重量单位自动换算（g / 斤 / t → kg）
- 条码生成后写回批次记录，并支持锁定（防止批次数据修改后条码失效）

## 包结构

```
code/
├── CodeController.java     # REST 接口（/code/* 路由）
└── CodeService.java        # GS1-128 编码生成逻辑
```

## 主要接口

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/code/generate/{batchId}` | 为指定批次生成 GS1-128 条码 |
| GET  | `/code/{batchId}` | 获取批次已生成的条码信息 |

## GS1-128 编码说明

条码包含以下应用标识符（AI）字段：

| AI | 字段 | 示例 |
|----|------|------|
| `01` | 全球贸易项目代码（GTIN） | `06901234567891` |
| `10` | 批次/批号 | `MOCK-2024001` |
| `310x` | 净重（kg） | `0001500` |
| `11` | 生产日期（YYMMDD） | `240115` |
| `17` | 保质期（YYMMDD） | `260115` |

详细标准参见 `文档/GS1编码标准说明.docx`。
